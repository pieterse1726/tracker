# Aligner Tracker — put it on your iPhone (free)

## 1. Host it on GitHub Pages (one time, ~10 min, on a computer)
1. Create a free account at github.com.
2. Click **+ → New repository**. Name it `aligner-tracker`, set it to **Public**, and click **Create repository**.
3. Click **uploading an existing file** and drag in ALL the files from this folder
   (index.html, manifest.json, sw.js, icon-192.png, icon-512.png, apple-touch-icon.png). Click **Commit changes**.
4. Go to **Settings → Pages**. Under "Branch" choose **main** and **/ (root)**, then click **Save**.
5. After a minute or two your app is live at `https://YOUR-USERNAME.github.io/aligner-tracker/`

Only the app's code is public. Your photos and data never leave your phone.

## 2. Add it to your Home Screen
1. Open that link in **Safari** on your iPhone.
2. Tap **Share → Add to Home Screen → Add**.
3. Always open the app from the Home Screen icon. Its data is separate from Safari's.

## 3. Back up
Settings → Create backup → Save backup file → Save to Files (iCloud Drive).
Deleting the Home Screen icon deletes the app's data, so back up every few weeks.

## Updating the app later
Upload the changed file(s) to the same GitHub repository. The app picks up the update the next time you open it while online.
